# Бронирование столиков (FastAPI Test Task)

Бэкенд для системы бронирования столиков в ресторане.

## Стек
* Python 3.12
* FastAPI
* SQLAlchemy 2.0 (async + aiosqlite)
* Pydantic v2
* SQLite

---

## Как запустить проект

1. Клонируйте репозиторий и зайдите в папку проекта.

2. Создайте и активируйте виртуальное окружение:
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # Mac/Linux:
   source venv/bin/activate

3. Установите зависимости:
   pip install -r requirements.txt

4. Создайте файл .env на основе примера:
   cp .env.example .env

5. Запустите сервер:
   uvicorn app.main:app --reload

После запуска Swagger-документация будет доступна по адресу: http://127.0.0.1:8000/docs

## Что реализовано

* Валидация через Pydantic:
  * Имена проверяются на спецсимволы.
  * Телефоны очищаются от мусора и приводятся к единому формату +7XXXXXXXXXX.
  * Время брони ограничено рабочими часами (12:00 – 22:00) с шагом в 1 час.
  * Дата не может быть в прошлом или дальше чем 90 дней вперед.
* Защита от двойного бронирования: если слот на это время уже занят активной бронью, сервер вернет ошибку 409 Conflict.
* Soft Delete: при запросе DELETE бронь не удаляется физически из базы, а меняет статус на cancelled.
* Автосоздание БД: таблицы создаются автоматически при старте приложения через lifespan, ставить Alembic для этого задания не потребовалось.

## Основные эндпоинты

* POST /bookings — создать новую бронь (код 201)
* GET /bookings — получить список всех броней (есть фильтр по дате: ?date=YYYY-MM-DD)
* GET /bookings/{id} — получить информацию о конкретной брони
* DELETE /bookings/{id} — отменить бронь (перевод в cancelled)
